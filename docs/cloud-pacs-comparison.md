## 1. この資料について

- 調査日は 2026-10-16。各社の公式サイトと比較記事の公開情報をもとにまとめた
- 料金・仕様は変わることがある。導入検討時は各社に見積もりと最新仕様を確認する
- 「記載なし」は、公開情報で確認できなかったことを表す（機能がないという意味ではない）
- 公式サイトで確認できず、比較記事にのみ載っていた値には「※記事」と付けた
- 比較対象は、クラウド（サービス事業者のデータセンター）に画像を保管する形態で提供されているものに限った。
  以下は今回の調査ではクラウド提供を確認できなかったため、比較対象から外した
  - Claio（ファインデックス）: 画像ファイリングシステム。公式ページにクラウド版の記載なし
  - iRad-IA（インフォコム）: DICOM イメージサーバ。公式ページを確認できず
  - PACS Caps-Web（スリーゼット）: オンプレ型。同社のクラウド型は PACS WATARU

## 4. サービス別の詳細

### 4.1 NOBORI（PSP）

- 院内に小型機器 NOBORI-CUBE を置き、画像をデータセンターで保管する
- 公式サイトでは保管検査数 2.7億件超、患者 ID 4,300万超と公表している
- ライセンス数を気にせず利用できるとしている
- 料金・データセンターの所在・認証は公式サイトに記載がなく、問い合わせが必要

### 4.2 LOOKREC（エムネス）

- 「クラウド型 DICOM データプラットフォーム」として、保管・閲覧・遠隔読影・病病連携をまとめて提供する
- 保管検査画像数は 700万人分超（2025年10月時点）
- ISMS クラウドセキュリティ認証を公表しており、比較対象の中では認証情報が最も明確
- 自社で遠隔画像診断サービスも提供しているため、読影の外部委託とセットで検討しやすい

### 4.3 Climis クラウドPACS（ジェイマックシステム）

- 料金が最も具体的に公開されている。定額・容量無制限で、画像が増えても月額が変わらない
- 同社の試算では 5 年総額は約159.5万円（オンプレ型 300〜500万円との比較）
- 初期費用としてゲートウェイPC（メイン・バックアップの 2 台）と設置費がかかる
- 自社運用のデータセンターを使う。院内からは VPN で接続する

### 4.4 SonicDICOM PACS Cloud（ディジタル）

- Web ブラウザだけで使え、低スペック端末でも動作するとしている
- 比較記事では月額 3,300円からの 4 プランと 14 日間の無料トライアルが紹介されているが、公式サイトは要見積もりの案内のみ
- 2025年6月にフジデノロからディジタルへ事業移管された。契約・サポート窓口を確認する

### 4.5 PACS WATARU（スリーゼット）

- 初期費用 0円、使用容量に応じた月額制のレンタル
- 国内の東西2拠点のデータセンターに二重保管しており、データ保管場所と冗長化が公開されている
- 同社はオンプレ型の Caps-Web も提供しており、クリニックで 1,700 件強の導入実績がある（※記事）

### 4.6 LSC PACS Xronos（ライフサイエンスコンピューティング）

- 院内サーバ型を基本とし、クラウドと併用できる。ソフトウェアのみの提供も可能
- 買い切り＋年間保守の料金体系で、他のサービスの月額制とは性格が異なる
- RIS・HIS・電子カルテとの連携に対応する

## 5. 参考: 海外勢・クラウド基盤サービス

国内での提供状況・提供形態は今回確認できていない。検討する場合は各社に確認する。

| 名称 | 概要 |
|---|---|
| AWS HealthImaging | AWS の医用画像保存サービス。DICOM を取り込み、PACS 等のアプリケーションから取り出す基盤として使う。PACS そのものではない |
| コニカミノルタ Exa | クラウド PACS / RIS。米国では AWS HealthImaging を基盤とした事例が公開されている |
| Sectra / Intelerad / Agfa / Fujifilm（SYNAPSE）等 | 海外ではクラウドホスト型・ハイブリッド型の PACS を提供している。国内向けクラウド版の詳細は公開情報で確認できなかった |

## 6. 選定時のチェックポイント

| 観点 | 確認すること |
|---|---|
| 料金体系 | 定額（容量無制限）か従量か。画像の増加ペースから 5〜10 年の総額を試算する |
| 院内設置機器 | ゲートウェイ等の要否、購入かレンタルか、故障時の交換費用と更新周期 |
| データ保管場所 | 国内データセンターか、冗長化（複数拠点・多重保管）の方式 |
| 3省2ガイドライン | 厚生労働省ガイドライン第7.0版、総務省・経済産業省ガイドライン第2.0版への対応状況。サービス仕様適合開示書の提供有無 |
| セキュリティ認証 | ISMS（ISO/IEC 27001）、ISMS クラウドセキュリティ（ISO/IEC 27017）、プライバシーマーク等 |
| 通信 | VPN か インターネット + TLS か。専用回線の要否 |
| 解約時のデータ | 画像の返却方法（DICOM 形式での一括エクスポート）、費用、期間。他社 PACS への移行実績 |
| 連携 | 使っている電子カルテ・RIS との連携実績と方式（患者 ID 起動、URL 連携、HL7 等） |
| ビューア | 医療機器認証の有無、対応端末、読影用途（高精細モニタ・マンモグラフィ）に使えるか |
| 障害時 | サービス停止時やネットワーク断のときの参照手段（院内キャッシュ等）、SLA |
| サポート | 対応時間、訪問対応の有無と費用、事業移管・撤退時の扱い |
